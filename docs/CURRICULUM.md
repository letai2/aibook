# مسیر پیوسته: از Python تا مدل و سامانه

نسخهٔ کنونی ۹۲ درس در ۱۵ بخش، ۱۵ ایستگاه عملی و ۱۰۷ واحد پیشرفت دارد.
هر درس یک دفتر Jupyter مستقل دارد؛ ۱۲ دفتر مرور اختیاری هم حفظ شده‌اند.
ترتیب اصلی و نگاشت مسیرها از `book_src/curriculum.py` ساخته می‌شود.

## حفظ پیوستگی و نشانی‌ها

۶۹ درس نخست در بخش‌های ۱–۹ از نظر متن، تمرین و ترتیب حفظ شده‌اند؛
آن مسیر پیش‌نیازهای واقعی را فراهم می‌کند و نیازی به تکرار آن نبود.
هفت درس پیشینِ بخش ۱۰ نیز حذف نشده‌اند: آموزش رفتار همان‌جا مانده،
RAG پس از بودجهٔ زمینه در بخش ۱۱ و هزینه/Cache پس از ساخت سامانه در بخش ۱۵ آمده‌اند.

هر ۷۶ شناسه و URL پیشین ثابت است، حتی اگر بخش آموزشی درس تغییر کرده باشد.
بنابراین URL قدیمیِ Cache هنوز با `part-10` شروع می‌شود ولی Breadcrumb و
مسیر مطالعه به بخش ۱۵ تعلق دارند. این سازگاری عمدی است.
۱۶ درس افزوده شده؛ هیچ درس موجود برای رسیدن به تعداد دلخواه خرد یا ادغام نشده است.
جمع‌بندی قدیمی RAG دیگر پایان کتاب نیست. دو مرور اولیهٔ Python هم import
غیرضروری PyTorch ندارند. پشتیبان پیش از گسترش، متن و کد پیشین را نگه می‌دارد.

## یک پروژه، دو سطح

۲۳ فرمان `mini_gpt.milestones` با شمارهٔ صفر تا ۲۲ همچنان ساخت هسته را
نشان می‌دهند. گسترش سامانه شمارهٔ اجرایی ساختگی به این فرمان اضافه نمی‌کند؛
با Notebookها و ماژول‌های کوچک همان بسته پیش می‌رود:

`instruction → context/retrieval → memory → tools/reasoning → assistant → evaluation/performance`

سناریوی پیوسته، راهنمای مطالعهٔ آفلاین با سندهای ساختگی دوره است.
مدل احتمال Token می‌سازد؛ برنامهٔ پیرامونی ورودی، شاهد، حافظه، مجوز ابزار،
تکرار و وارسی را مدیریت می‌کند. تغییر این اجزا لزوماً وزن‌ها را عوض نمی‌کند.

Fixture ازپیش‌نوشته‌شده، آزمون کنترل برنامه است. اتصال واقعی Mini-GPT هم وجود
دارد و خروجی خامش ثبت می‌شود؛ شکست قالب با جواب آماده پنهان نمی‌شود.
آموزش چند پاسخ کوتاه یا قبولی اتصال، شاهد ساخت دستیار عمومی نیست.

## تمرین، زمان و بازگشت

موضوع تازه از محدودیت ملموس آغاز می‌شود؛ محاسبه یا Trace دستی پیش از API
می‌آید. دفترها مثال، TODO مستقل، تغییر یک عامل، خرابی عمدی، اصلاح و تأمل
دارند؛ راه‌حل‌ها بیرون دفتر یادگیرنده‌اند. ایستگاه‌ها تکلیف ترکیبیِ جدا دارند.
تحویل پایان مسیر شامل مورد موفق و شکست توضیح‌داده‌شده است.

زمان درس خواندن و نیمهٔ عملی را یک بار حساب می‌کند.
[روش برآورد](LEARNING_TIME.md) فرض‌ها و استثناها را توضیح می‌دهد.
جمع دقیق فصل و بخش از همان درس‌ها تولید می‌شود؛ مرور اختیاری، نصب و آموزش
طولانی جداست. هدف توان توضیح و تغییر کد است، نه سرعت.
