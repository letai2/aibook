# ممیزی و نقشهٔ تغییر — ویرایش سوم

تاریخ بررسی: ۲۰۲۶-۰۹-۱۹. پیش از ویرایش، همهٔ ۶۷ درس و پاسخ، ۱۰ ایستگاه، کد مدل/مرحله‌ها/آزمون‌ها، راهنماها، سازندهٔ HTML، CSS و JavaScript خوانده شدند. خروجی تولیدی ۲۳۵ صفحه، ۱۶۷۳۵ پیوند/دارایی و ۲۴ آزمون اجرایی سالم داشت؛ سلامت پیوند و اجرا به معنی کفایت آموزشی یا طراحی نیست. نسخهٔ پیشین در `archive/edition-2-snapshot.zip` محفوظ است.

## مقایسهٔ سرفصل؛ نه اقتباس محتوا

صفحهٔ عمومی [یادگیری عمیق هوسم](https://howsam.org/downloads/deep-learning-course/) ترتیب مبانی شبکه، بهینه‌سازی، پایداری آموزش و سپس خانواده‌های معماری را نشان می‌دهد. برای مسیر ما، پل کوتاه شبکهٔ بازگشتی و برنامهٔ نرخ یادگیری ارزشمند است؛ فصل‌های تصویر، GAN، گراف و صوت خارج از هدف‌اند.

صفحهٔ عمومی [ساخت مدل زبان هوسم](https://howsam.org/downloads/implementing-chatgpt-from-scratch-with-pytorch/) پیش‌نیاز یادگیری عمیق و PyTorch را فرض می‌کند و مسیر مدل پایه، تنظیم دستوری و ترجیح را جدا می‌کند؛ LoRA نیز در فهرست توسعه‌هاست. این کتاب آن پیش‌نیازها را خودش می‌سازد و پس‌آموزش را آشنایی مفهومی نگه می‌دارد. هیچ متن، ویدئو، کد یا مثال دوره کپی نشده است.

نشانی [یادگیری ماشین با پایتون مکتب‌خونه](https://maktabkhooneh.org/course/یادگیری-ماشین-پایتون-mk1318/) هم با ابزار وب و هم در مرورگر باز شد، اما هر دو فقط پوستهٔ ناوبری سایت را نشان دادند؛ سرفصل جزئی قابل تأیید نبود. بنابراین هیچ ادعای ساختگی دربارهٔ پوشش آن مبنای تصمیم نیست. فهرست مبانی لازم با نیازهای واقعی ساخت مدل و درخواست خواننده سنجیده شده است.

## قرارداد طراحی

کتاب یک «کارگاه با دفتر پژوهش» است: متن روی کاغذ روشن، آزمایش روی میز تیره، یادداشت روی برگهٔ خط‌دار. آبی برای مفهوم/مسیر، سبز برای شاهد اجرایی، کهربایی برای تمرین و قرمز محدود برای خطا. معنا علاوه بر رنگ با عنوان و متن می‌آید. گونهٔ درس تابع کاری است که خواننده می‌کند: استدلال، محاسبه، ساخت، عیب‌یابی یا تأمل. تفاوت تصادفی رنگ جای طراحی نیست.

نمودار بلوک، معماری واقعی **Pre-Norm** را نگه می‌دارد: `x + Attention(LN(x))` سپس `y + FFN(LN(y))`. تشبیه «نگاه‌کردن» فقط برای وزن‌دهی اطلاعات است؛ مدل ذهن انسان یا علت قابل اعتماد برای پاسخ ندارد. وزن توجه، شاهد یک محاسبه است نه توضیح علّی کامل رفتار.

## مرز کار

GPU، آموزش چنددستگاهی، tokenizer تولیدی BPE، KV cache و fine-tuning واقعی جزو پیاده‌سازی این نسخه نیستند. مدل مرورگر نیز شبکه را آموزش نمی‌دهد: ابزارهای کوچک، محاسبات آموزشی‌اند و بازرس، JSON خروجی واقعی Python را نمایش می‌دهد. هیچ سرویس، حساب، انتشار بیرونی یا وابستگی نمایشی اینترنتی افزوده نمی‌شود.
