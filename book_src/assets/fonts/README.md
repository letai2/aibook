# Reading font

Vazirmatn v33.003, unmodified variable WOFF2 (weights 100–900).
Source: https://github.com/rastikerdar/vazirmatn/tree/v33.003
File: fonts/webfonts/Vazirmatn[wght].woff2
License: SIL Open Font License 1.1; see OFL-Vazirmatn.txt.

The build copies the font and complete license to dist/assets/fonts. No external
font request is made by the book. Prose uses Vazirmatn; code retains its separate
Consolas / Courier New / monospace stack. Font display uses swap so reading is
never blocked by a missing or slow font.
